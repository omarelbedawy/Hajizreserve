How it works

01

Register the flight

Before departure, enter the flight number, date, and the hotel that needs to know if things go sideways.

02

Our system checks the flight automatically once it's underway. No app to open, nothing to remember.

03

Proof, if it's needed

If the delay clears the threshold, the hotel gets an email with a verification code they can check anytime, themselves.

Register a booking

Do this before the flight departs. You'll get a verification code back — save it, it's what the hotel will use to confirm everything themselves.

Verification code
--------

Give this code to the traveler, or the hotel will receive it directly by email if a delay is confirmed. Anyone can check status any time at /verify/<code>.

Verify a booking

For hotel staff. Enter the code from the traveler or the notification email — no login required.
